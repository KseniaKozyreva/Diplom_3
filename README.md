# Автоматизация UI-тестирования веб-приложения Stellar Burgers 
Данный проект содержит пакет автотестов для проверки ключевого функционала веб-приложения **Stellar Burgers**. 
Тестирование реализовано на фреймворке **PyTest** с использованием библиотеки **Selenium WebDriver** и паттерна **Page Object Model (POM)**.

## 💻 Реализованный функционал и покрытие

Проект разделен на две логические части:
1. **Основная часть (`test_main_page.py`):** Проверка работы Конструктора, переходов по разделам сайта, кликов по ингредиентам и базовой логики главной страницы.
2. **Лента заказов (`test_order_feed.py`):** Проверка динамического обновления счётчиков ("Выполнено за все время", "Выполнено за сегодня") и отображения созданных заказов в Ленте.

## 🚀 Инструкция по развертыванию проекта

### 1. Клонирование и подготовка окружения
Убедитесь, что у вас установлен Python 3.10+. Создайте и активируйте виртуальное окружение, после чего установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запуск тестов
Запуск всех тестов проекта в обоих браузерах подряд:
```bash
bash python -m pytest tests/ -v
```

Запуск конкретного файла только в Chrome:
```bash
bash python -m pytest tests/test_order_feed.py -k "chrome" -v
```

Запуск первой части только в Firefox:
```bash
bash python -m pytest tests/test_main_page.py -k "firefox" -v
```

---

## 📊 Генерация отчетов Allure

1. Запустите тесты со сборкой результатов:
```bash
bash pytest tests/ --alluredir=allure-results
```

2. Сгенерируйте и откройте интерактивный отчет в браузере:
```bash
bash allure serve allure-results
```

## 🎯 Итоги работы

* Спроектирована и реализована архитектура автотестов по методологии **Page Object Model (POM)**, что обеспечивает высокую читаемость и простоту поддержки кода.
* Настроен стабильный кроссбраузерный запуск тестов для браузеров **Google Chrome** и **Mozilla Firefox**.
* Реализованы явные ожидания (**WebDriverWait**) для обработки динамических элементов интерфейса и анимаций.
* Подключен фреймворк **Allure** для детального анализа результатов прохождения UI-сценариев.
